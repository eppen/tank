# 坦克大战（tank_game）

文件：`tank_game.py`（游戏主体）、`tank_keys.json`（开火键配置，可删，会自动重建）、`tank_preview.png`（预览截图）、`_selftest*.py` / `_preview.py`（自测与截图脚本，其中 `_selftest_lives.py` 专测生命值与复活）。

**下文所有命令都在本目录（`tank/`）下执行**，例如 `cd tank && python3.11 tank_game.py`。

## 生命值（每人 5 条命）

- 每台坦克 **5 条命**。血条（`MAX_HP = 100`）打空算「被击毁一次」，**扣 1 条命**，不再直接分胜负。
- 被击毁后原地消失，**1 秒后（60 帧）在出生点满血复活**：位置、朝向回到开局点，冷却清零。
- 复活后有 **1 秒（60 帧）无敌**：车体外围会显示一圈白环，这期间挨打不掉血（子弹会被弹掉），避免刚出生就被补枪。
- 死亡等待期间，出生点上会显示 `RESPAWN 1.0s` 倒计时；命数扣到 0 才判负、出现胜负提示。
- 命数显示在屏幕左上/右上：`HP xxx` 下面一排 5 个小方块，亮的 = 还有的命，暗的 = 已经丢掉的。
- 三个数字都写死在 `tank_game.py` 里，不开放环境变量：`MAX_LIVES = 5`、`RESPAWN_DELAY = 60`（帧）、`SPAWN_INVULN = 60`（帧）。
- 被击毁、复活、命尽都会在终端打一行 `[life] ...` 日志，方便对表确认流程。

## 手柄支持

游戏里有两条手柄通道，启动时自动选择：

1. **SDL 标准通道（首选）**：手柄在 SDL 内置映射库里查得到，就按语义读取（左摇杆、ABXY、模拟扳机、Start/Back），不用记轴号按钮号，插上即可用。
2. **原始 joystick 兜底**：SDL 不认这台设备（映射库里没有它的条目）时，按 XInput 常见布局猜——左摇杆 = 轴 0/1，开火 = 按钮 0–3，十字键读 hat。猜错了用下文的 `TANK_PAD_AXES` 等开关改。

先确认自己在哪一档：

```bash
python3.11 tank_game.py --pad-scan
# 无显示器 / SSH / CI 环境加 dummy 驱动，只做诊断
SDL_VIDEODRIVER=dummy python3.11 tank_game.py --pad-scan
```

每台设备后面会跟一行判定：

| 扫描输出 | 含义 |
| --- | --- |
| `-> 标准映射（SDL 认，直接可用）` | 走第 1 条通道，不用再调 |
| `-> 无 SDL 映射 → 走原始 joystick 兜底` | 走第 2 条通道，摇杆/开火不对就按调参表改 |
| `-> 无 SDL 映射，且兜底已被 TANK_PAD_RAW=0 关闭` | 兜底被环境变量关掉了，这台设备用不了 |

### 兼容性

判定依据（实测这台机器上 pygame 2.6.1 自带的 SDL 2.28.4 映射库）：Xbox 条目 16 条（USB 10 / 蓝牙 6），8BitDo 条目 40 条（含 AB 互换的重复项）**全部以 `0300`（USB）开头，`0500`（蓝牙）0 条**。查不到映射表的设备一律落到兜底通道。

| 手柄 | Windows 2.4G / 有线 | Windows 蓝牙 | macOS 有线 | macOS 蓝牙 |
| --- | --- | --- | --- | --- |
| Xbox 官方（Series X·S / One S / Elite） | ✅ 走 XInput，不查映射表 | ✅ | ✅ | ✅ |
| 8BitDo 猎户座 XPro | ✅ Xbox 授权，即插即用 | 🟡 官方规格里 PC 走 2.4G/有线，蓝牙主要面向 Apple/Android | 🟡 看固件上报的 VID 是否被当成 Xbox，`--pad-scan` 一验便知 | 🟡 |
| EasySMX X05 | ✅ 切到 XInput 模式后 | — 无蓝牙 | 🟡 | — |

- ✅ 直接可用；🟡 能玩，但要走兜底通道，摇杆轴或扳机可能要按调参表指定；— 该连接方式不存在。
- macOS 蓝牙要求 macOS 11+（Apple Silicon 建议 12+）；`--pad-scan` 里显示「标准映射」就说明系统层和 SDL 都认了。
- 想确认手柄是不是原厂：Xbox 官方手柄的 GUID 形如 `030000005e04…`（USB）/ `050000005e04…`（蓝牙），`5e04` 就是微软 VID `045e` 的字节序。仿品/翻新常被改成别的 VID，正好落进兜底通道——能玩，但要调参。

**两只不同型号能同时用吗**：能，两只手柄各走各的通道、各自算上升沿，互不干扰（同型号更是没问题）。要注意三点：

1. **槽位顺序不是纯插入顺序**：先排所有 SDL 认得的（标准通道），再排兜底通道的。所以「一只标准 + 一只杂牌」时，标准那只固定是 P1（红），杂牌那只固定是 P2（蓝），跟谁先插无关。
2. **调参开关是全局的**：`TANK_PAD_AXES` / `TANK_PAD_FIRE` / `TANK_PAD_RAW_TRIGGERS` 对两只手柄一起生效，只有扳机轴按通道分开（标准 `(4,5)`、兜底空）。所以混插时如果为了救兜底那只去改 `TANK_PAD_AXES`，标准那只的左摇杆也会被带偏（实测：`TANK_PAD_AXES="2,3"` 下标准手柄从 `turn=+1.00` 变成 `+0.00`）。要混插，优先挑**两只都进 SDL 映射库**的型号。
3. **震动只有标准通道有**：兜底那只不震，标准那只正常震。

买之前先跑一遍 `--pad-scan`（型号能查到有人用过、输出「标准映射」最稳）；已经在手的可以用 `TANK_PAD_SCAN=1` 直接验。

### 需要买功能复杂的手柄吗

不需要，功能多在这个游戏里基本用不上：

- **游戏只读三样东西**：左摇杆 X/Y（外加十字键当成 hat 的那一路）、任意一个开火按钮、START/BACK 重开。右摇杆、扳机行程、体感、连发/宏、多套配置档代码里一次都没读；背键也只在你按 F4 主动绑定时才有意义。
- **开火是上升沿**（按住只打一枪，冷却 18 帧），所以 turbo、微动扳机、自适应扳机这些卖点在这里没有任何体现；摇杆只有「满推 / 半推」两种手感，精度要求很低。
- **震动只是装饰**：只在被击毁时震 180ms，没有也不影响游戏。
- **真正值得在意的是两条**：系统/SDL 认不认得（决定走标准通道还是兜底通道）、2.4G 接收器别在系统里报成「键盘+鼠标」组合设备（那样游戏根本看不见它）。

结论：能切 XInput 的百元内手柄就够，两只同型号最省心；霍尔摇杆、1000Hz 回报率、RGB 这类溢价点在这个游戏里不用考虑。

### 调参开关

| 开关 | 作用 | 示例 |
| --- | --- | --- |
| `--pad-scan` / `TANK_PAD_SCAN=1` | 只打印识别结果 + 排错建议，不进游戏 | `python3.11 tank_game.py --pad-scan` |
| `TANK_PAD_DEBUG=1` | 打印手柄打开信息、每个按钮事件、坦克反查结果 | `TANK_PAD_DEBUG=1 python3.11 tank_game.py` |
| `TANK_PAD_AXES="x,y"` | 换左摇杆轴号，**标准通道和兜底通道都生效** | `TANK_PAD_AXES="2,3"` |
| `TANK_PAD_FIRE="..."` | 开火按钮号列表；标准通道下是语义号（0=A 1=B 2=X 3=Y 4=BACK 6=START 9=LB 10=RB 11–14=十字键 …） | `TANK_PAD_FIRE="9,10"` 只用肩键 |
| `TANK_PAD_RAW_TRIGGERS="l,r"` | **仅兜底通道**：启用扳机轴开火 | `TANK_PAD_RAW_TRIGGERS="4,5"` |
| `TANK_PAD_RAW=0` | 整体关闭兜底通道，只认 SDL 标准手柄 | `TANK_PAD_RAW=0 python3.11 tank_game.py` |
| `TANK_KEYS_FILE=...` | 开火键配置文件位置（默认脚本同目录 `tank_keys.json`） | `TANK_KEYS_FILE=/tmp/k.json` |
| `TANK_MODE` / `TANK_AI` | 开局模式与 AI 难度，等价 `--1p` / `--ai=hard` | `TANK_MODE=1p TANK_AI=easy` |

两条固定参数（写在 `tank_game.py` 里，不开放环境变量）：摇杆死区 `PAD_DEADZONE = 0.25`（死区外线性过渡，不是非黑即白），扳机过 `PAD_TRIGGER_ON = 0.5`（行程一半）即算开火，脉冲扳机的两段手感不影响这个判定。

兜底通道下扳机默认**关**，原因是轴号只能靠猜，猜错就会变成「一直开火」；确认轴号后显式打开即可。

### 操作与改键

| 动作 | 手柄 | P1 键盘 | P2 键盘 |
| --- | --- | --- | --- |
| 转向 | 左摇杆左右（十字键被 SDL 报成 hat 的型号也可用） | A / D | ← / → |
| 前进、后退 | 左摇杆上下（同上） | W / S | ↑ / ↓ |
| 开火 | ABXY 任一、LB/RB、RT/LT | SPACE（可改） | ENTER（可改） |
| 重开（分出胜负后） | START / BACK | R | R |
| 切模式 / 切难度 / 改键 / 退出 | — | F2 / F3 / F4 / ESC | 同左 |

- 开火是**上升沿**：按住只打一枪，不会连发；冷却 18 帧（约 0.3 秒）。
- 胜负：一方 **5 条命全丢**才算输；中途被打掉命只是复活，不会结束这局。按 R / START 重开一局会把双方血量和命数一起重置。
- 改键：按 **F4** → `1`/`2` 改键盘 P1/P2（按一下新键），`3` 改手柄（按一下手柄按钮），`0` 恢复默认（SPACE / ENTER / ABXY+肩键）。改完立刻原子写入 `tank_keys.json`，下次启动自动读回；配置读坏或键名非法会退回默认并打印原因，不会开不了游戏。ESC 或 F4 关闭面板，面板打开时对战暂停。
- ESC 和 F1–F4 是保留键，不能被绑成开火键。
- 手柄的背部拨片（8BitDo 猎户座 XPro、Xbox Elite）在标准通道下是语义按钮 16–20，HUD 里显示 `PADDLE1` 等，可直接在 F4 面板里绑定；猎户座 XPro 的拨片也可以先用 8BitDo 官方软件映射成任意键再用。

### 已知限制

- **复活是原坦克复位，不重建对象**：命还在时被击毁 → 1 秒后回到出生点，血量、冷却、闪白、无敌全部按复活规则重置；屏幕上飞着的子弹不会跟着清掉。
- **极端同帧互毁**：双方最后一发子弹在同一帧互相命中时，胜负提示以后处理的那一方为准（两车都没命了，谁的名字出现算谁赢）。
- **兜底通道没有震动**：原始 joystick 没有 rumble 通道；标准通道下**被击毁那一方**的手柄会震一下（`PAD_RUMBLE_MS = 180`）。
- **十字键只当 hat 读**：`Gamepad._hat()` 读的是 `joystick.get_hat(0)`，所以 SDL 把 dpad 映射成 hat 的手柄（Xbox 系列、Elite 等）十字键可用；映射成按钮（如老 Xbox 360 有线 `dpup:b11`）的型号，十字键不参与转向，请用左摇杆。
- **单人模式下第二只手柄不参与**：P2 由电脑控制，第二只手柄留给切回双人（F2）时用。
- **两只手柄 = 两台坦克**：P1（红）= 第一只，P2（蓝）= 第二只；混插不同通道时标准通道那只固定排第一（见上文「两只不同型号能同时用吗」）。
- 蓝牙重连后设备 index 会变，游戏按 `instance_id` 反查坦克并自动重建绑定，但归属仍按「重新接入的顺序」重排。
- EasySMX X05 这类 XInput/DInput 双模手柄在 PC 上要先切模式：按住 `BACK+START` 约 3 秒，指示灯变蓝即 XInput；`--pad-scan` 的输出里也会提示这一条。
